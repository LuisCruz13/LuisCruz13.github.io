Inicio Política de Privacidad Condiciones del Servicio

Esta política explica qué información usa contenido-publicación (la "Aplicación"), una herramienta personal operada por Luis Sotero Cruz Gómez (el "Responsable"), y cómo la protege.

1. A quién aplica

La Aplicación es de uso personal. Solo se conecta a las cuentas de YouTube y TikTok de su propio Responsable. No ofrece registro, no tiene usuarios externos y no accede a cuentas ni datos de otras personas.

2. Información que se usa

  • Autorizaciones de acceso (tokens OAuth) que el Responsable otorga a la Aplicación en Google/YouTube y en TikTok.
  • Datos básicos del canal o la cuenta que esas plataformas devuelven al autorizar o al subir un video (por ejemplo, el identificador del video publicado).

La Aplicación no recopila nombres, correos, ubicación, contactos ni datos de espectadores.

3. Para qué se usa

Exclusivamente para subir los videos que genera la Aplicación al canal de YouTube y a la cuenta de TikTok del Responsable, y para confirmar que se publicaron. No se usa para publicidad, perfiles, análisis de personas ni ningún otro fin.

4. Datos de usuario de las APIs de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las APIs de Google se apegan a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado. La Aplicación solicita únicamente el permiso necesario para subir videos a YouTube.

5. Con quién se comparte

Con nadie. La información no se vende, no se renta y no se comparte con terceros. Solo viaja entre la Aplicación y las propias plataformas (Google/YouTube y TikTok) para publicar el video.

6. Cómo se guarda

Los tokens se guardan cifrados en la infraestructura privada que usa el Responsable para ejecutar la Aplicación (secretos cifrados de GitHub Actions o su propio equipo) y nunca se publican. Se conservan mientras la Aplicación esté en uso y se eliminan cuando el Responsable revoca el acceso.

7. Cómo revocar el acceso

  • Google/YouTube: myaccount.google.com/permissions
  • TikTok: Configuración y privacidad → Seguridad → Apps y servicios autorizados.

Al revocarlo, la Aplicación deja de poder publicar de inmediato.

8. Cambios a esta política

Si la política cambia, se actualizará en esta página con su nueva fecha de vigencia.
